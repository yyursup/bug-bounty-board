Methodology

Source of truth

Each program comes from the platform's own public data feed, the same data their websites show. Only permanent bug bounties are listed; audit contests and attackathons are left out.

Max is a ceiling

The headline number is the cap for the top severity. Real payouts depend on impact, funds at risk and each program's rules. Token amounts are shown as the program states them.

Freshness

● program updated within 14 days, ● within 90 days, ● older. Cantina doesn't publish an update date, so its cards show the launch date.
